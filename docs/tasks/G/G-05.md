## Goal
A Config view that edits the .ini files of the run folder: `run/login/config` and `run/game/config`, using G-01's run folder.

1. **Files and keys.**
   - A file list per server. For each file, its keys in file order, grouped by the comment headers of the file.
   - Each key has:
     - an editor for its value: a text field, a check box for booleans, or a number field with a range check for numbers;
     - the **comment lines above it** as help text;
     - the Java default from the generated config structs, with a "reset to default" button;
     - a marker when the value differs from the default.
2. **Search** over all keys and comments.
3. **Save.**
   - Write only the changed values, in place. Keep the comments, the order and the line endings.
   - G-02 needs the same writer, so put it in `l2-config`. If G-02 lands first, use its writer.
   - Afterwards show "restart the login/game server to apply" for the changed files.
4. **Secrets.** `Password`, `Token` and the `Login` of `Database.ini` are shown masked and written only when changed.
5. **Rust-only files.** List `Admin.ini`, `SideBySide.ini` and `GeoOverride.ini` too, with their help text.
