## Goal
Opening `l2-admin-gui` on its own must just work: no "connection refused" and no token to type.

1. **Find the run folder.**
   - The GUI looks for `run/supervisor.ini`, in this order:
     - the repo the exe belongs to (`<exe>/../../run`);
     - `./run`;
     - the exe's own folder.
   - It remembers the folder it chose in its settings.
   - A "Choose run folder" button covers other layouts.
2. **Read the connection from `supervisor.ini`.**
   - `Listen` gives the URL and `Token` gives the token. The token is never shown and never logged.
   - The token field in the connection view becomes optional and only overrides the file.
3. **Start the supervisor when nobody listens.** When the connection is refused:
   - Start `l2-supervisor` (next to the GUI exe) with that `supervisor.ini`.
   - Start it **detached** (D-56), so it keeps running when the GUI closes:
     - Windows: no console window (`CREATE_NO_WINDOW | DETACHED_PROCESS`).
     - Linux: its own session (`setsid` / `process_group`).
   - Send its stdout and stderr to `run/log/supervisor.log`.
   - Then connect with the bridge's backoff.
   - Never start a second supervisor. Check the port first, and check the lock file `run/supervisor.pid` (pid and exe path). The supervisor writes that file at start and removes it at exit.
4. **Status bar.** It shows "Supervisor: running / starting / not found (path)", with the reason in plain words: `supervisor.ini` missing, Token empty, port used by another program, or exe missing.
5. **Servers view.** Add "Start all" and "Stop all" buttons next to the per-server ones. Start all goes in the `Servers` order; Stop all goes in reverse.
6. **Stop the supervisor.** A button that asks first, stops all servers cleanly through the API, and then lets the supervisor exit.
7. **No `run/supervisor.ini` yet.** Show the hint "Run the setup wizard". G-02 adds the wizard; until it lands, the hint names the README section.
