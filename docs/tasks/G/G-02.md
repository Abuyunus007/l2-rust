## Goal
A first-start wizard in the GUI that turns the repo into a working install, with no file edited by hand.

1. **Run folder.**
   - Create `run/login` as a copy of `dist/login`, and `run/game/config` as a copy of `dist/game/config`.
   - Never overwrite an existing file without asking. Show which files already exist.
2. **Database.**
   - Ask for host, port, user, password and database name.
   - Write them into both `Database.ini` files with the same keys as Java. `URL = jdbc:mysql://host:port/name?...` stays exactly as the Java default, with these values filled in.
   - "Install database" runs the `l2-db-installer` library inside the GUI. It asks the same questions (Reset / Keep / Cancel, Continue / Abort) and shows progress and a log.
3. **Servers.**
   - Login ports: `LoginserverPort` and `LoginPort`.
   - Game port and server id: `GameserverPort` and `RequestServerID`.
   - `DatapackRoot`: the repo's `dist/game` as an absolute path with forward slashes.
   - Geodata folder: default `dist/game/data/geodata`. Warn when it has no `.l2j` files.
   - An optional Java game server entry for side by side. When it is used, also show the `SideBySide.ini` switches with their help text.
4. **Secrets.**
   - Generate random tokens for `run/login/config/Admin.ini`, `run/game/config/Admin.ini` and `supervisor.ini`, and set `Enabled = True` in both `Admin.ini` files.
   - Write `run/supervisor.ini` from `crates/l2-supervisor/supervisor.example.ini`, with the paths of this repo (`../target/release/...`).
5. **Check page.**
   - Show what is ready and what is missing: are the release exes built, is there geodata, is the database reachable? Test the database only after the user presses "Test connection".
   - Then "Start servers", which uses G-01.
6. **Open again later.** The wizard can be opened again from the menu ("Setup"). It then shows the current values.

## Files
- `crates/l2-admin-gui/src/views/setup*.rs` (new), and the menu entry.
- `crates/l2-db-installer`: make `installer` usable from another crate without the egui main, if that is needed.
- `crates/l2-config`: an .ini writer that keeps comments and order, if there is none yet.
- `README.md`: installation describes the wizard first and the manual steps as the alternative.

## Requirements
- Edit .ini files in place: change only the values of the keys, and keep the comments, the order and the line endings.
- The password is written only to `run/.../Database.ini`. It is never logged and never stored in the GUI settings file.
- No database connection is made before the user presses Test connection or Install.
