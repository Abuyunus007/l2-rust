## Goal
A buildable Cargo workspace with the shared lint/format setup, the two base crates `l2-util` and `l2-testkit`, a LICENSE, and CI that actually runs fmt/clippy/test.

## Java source (the spec)
- `C:\l2-rust\l2jmobius\java\org\l2jmobius\commons\util\Rnd.java`: what randomness the Java code needs (nextInt, get(min,max), nextBytes, nextDouble)
- License header of any Java file (MIT, "Copyright (c) 2013 L2jMobius")

## Reference implementation to copy
none (this card creates it)

## Files
Create:
- `Cargo.toml` (virtual workspace: `members = ["crates/*"]`, `resolver = "3"`, `[workspace.package]` edition 2024, `[workspace.dependencies]`, `[workspace.lints]`)
- `rust-toolchain.toml` (stable channel, rustfmt + clippy)

## Requirements
1. `[workspace.dependencies]` lists the approved crates (D-28): tokio, tokio-util, bytes, futures-util, thiserror, anyhow, tracing, tracing-subscriber, tracing-appender, serde, serde_json, rand, rand_chacha, blowfish, cipher, rsa, num-bigint-dig, sha1, base64, sqlx (mysql, runtime-tokio, tls-rustls), quick-xml, tokio-tungstenite, eframe, egui, png, clap, hex, dashmap, subtle, prettyplease, syn, quote; dev-only: proptest, tempfile. Versions are resolved with `cargo add` at creation time. Member crates use `x.workspace = true`.
2. Workspace lints: `unsafe_code = "forbid"`, clippy `all` = warn, plus `unwrap_used`/`expect_used` = warn (allowed in tests via `#[cfg(test)]`/`clippy.toml` `allow-unwrap-in-tests`).
3. `l2-util`:
   - `WorldRng`: seedable (ChaCha), `from_seed(u64)`, `from_entropy()`. Methods mirroring `Rnd`: `next_i32()`, `get(min, max)` (inclusive, like Java), `next_bytes(&mut [u8])`, `next_f64()`. Doc comment: game logic must use this (D-13).
   - `time::now_millis() -> i64` (Java `System.currentTimeMillis` semantics).
   - `ids::ObjectId(i32)` newtype with `Debug/Clone/Copy/Eq/Hash/Ord`, serde.
4. `l2-testkit`:
   - `vectors::load<T: DeserializeOwned>(name: &str) -> T` reads `java-vectors/out/<name>.json`, found relative to `CARGO_MANIFEST_DIR` of the workspace root.
   - `hex` helpers for asserting byte slices with readable diffs.
5. CI green on Windows and Linux.
