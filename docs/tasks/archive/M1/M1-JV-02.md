## Requirements
1. For each packet: name, opcode, input field values, and the **plaintext payload bytes** (opcode included, without length header and without encryption).
2. At least 2 variants per packet with non-trivial values (non-ASCII UTF-16 strings, negative ints, max values).
3. Packets that can't be produced standalone are listed in the JSON under `"skipped"` with the reason (they'll be covered by captures).
