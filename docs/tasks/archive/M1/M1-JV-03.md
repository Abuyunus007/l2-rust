## Goal
Vectors from the real Java geodata classes so the Rust parser (M1-GEO-01) can be checked cell by cell.

## Java source (the spec)
Base: `C:\l2-rust\l2jmobius\java\org\l2jmobius\gameserver\geoengine\`
- `geodata\regions\Region.java`, `geodata\blocks\{FlatBlock,ComplexBlock,MultilayerBlock}.java`, `geodata\IBlock.java`, `geodata\IRegion.java`, `geodata\Cell.java`
- Background: `docs/analysis/05-geodata.md`

## Requirements
1. Load the region with `new Region(ByteBuffer LITTLE_ENDIAN)` exactly like `GeoEngine.loadRegion`.
2. Sample 2,000 cells per file with a fixed seed: (geoX, geoY within the region, worldZ ∈ {-16000, -2000, 0, 2000, 16000, and the cell's own nearest Z}). Record `getNearestZ`, `getNextLowerZ`, `getNextHigherZ`, `checkNearestNswe` for all 4 single directions, and the block type.
3. Also record the per-region block type counts (must match `docs/analysis/05-geodata-comparison.csv`).
4. Keep the files small: < 1 MB each.
