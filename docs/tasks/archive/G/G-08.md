## Goal
The game server's XML configs get a form each in the GUI, so the owner never has to edit XML by hand. They are listed as topics next to the `.ini` topics of G-07, under "XML configs".

| File | Form |
|---|---|
| `AccessLevels.xml` | A table of access levels. Each level has its number, name, name and title colour (with swatches), child access, and the permission flags as on/off switches (`isGm`, `allowPeaceAttack`, `allowFixedRes`, …, every attribute the file uses). Add, copy and delete a level. |
| `AdminCommands.xml` | All admin commands with their access level (a drop-down from AccessLevels) and `confirmDlg` as a switch. Search and filter by level. "Set the level for all shown" for bulk changes. |
| `ClassMaster.xml` | The class change settings and the per-class item rewards and costs (tables). |
| `DynamicExpRates.xml` | The level ranges with exp and sp rates (table with sliders). |
| `SiegeSchedule.xml` | Per castle: the day (drop-down) and the hour (slider 0–23), with siege enabled as a switch. |
| `BotReportPunishments.xml` | The report count, then the punishment skill and the system message (table). |
| `SecondaryAuth.xml` | Enabled (switch), max attempts, ban time, recovery link, forbidden passwords (list). |
| `Scripts.xml` | Present for completeness: the script list as a read-only view, because Rust scripts are compiled in (D-16). |
| `default-ipconfig.xml` | The ip config entries (gameserver address, subnets) as a table. |

Rules:
1. **Read and write the same XML structure** the Java loaders and the Rust loaders read: the same element and attribute names.
   - Keep the comments of the file.
   - Keep the attribute order where possible.
   - Keep the line endings.
   - A round trip with no change must give an identical file. Write the XML with care for the existing formatting. If a full parser and writer cannot keep formatting, edit attributes in place, the way `ini_edit` does for `.ini` files.
2. **Validate before saving:** unique access level numbers, known commands, hours 0–23, and so on. Show the errors next to the field.
3. **"Restart needed" after saving,** as for `.ini` files. Or, where the game server has a `//reload` for that file (`//reload access`, `//reload config`?), offer "Reload now" through the G-03 console.
