## Goal
The owner wants every `.ini` setting of the login and game server editable in a pleasant UI, with no need to touch files. G-05 already edits every file. This card reworks how the editor looks and is organised. It writes the files exactly as before (`l2_config::ini_edit`).

1. **Organised by topic.** The left side lists topics, each grouping settings from several files:
   - Server & network, Database, Rates, Player, Character creation, PvP & karma, Party & clans, NPCs & monsters, Grand bosses, Sieges & residences, Olympiad, Seven Signs, Events, Geodata, Chat & flood, Side by side (Rust-only), Admin (Rust-only).
   - One topic per `Custom/*.ini` feature, under "Customs".
   - Every key of every dist `.ini` belongs to exactly one topic. Put the mapping in a committed table (`crates/l2-config/src/topics.rs` or a data file). A test fails when a dist key has no topic.
   - Each setting shows its file name in small print. Search over keys, comments and topics stays.
   - A "By file" toggle keeps the G-05 view for those who want it.
2. **Controls by type.**
   - **Booleans:** an on/off switch (a toggle, not a plain check box).
   - **Numbers with a known range:** a **slider** plus a number field next to it, so values outside the slider range can still be typed. The field accepts any valid value of the type; the slider just clamps visually. The range comes from a committed **range table**, one entry per key or key pattern, with min, max, step and an optional unit. Build it from the Java comments and code: rates 0–100, chances and percentages 0–100, levels 1–85, ports 1–65535, seconds and minutes, multipliers 0–10, and so on. A test checks that every entry names an existing key and that its default lies inside the range.
   - **Numbers without a range:** a drag value with +/- buttons.
   - **Enum-like keys,** where the comments list the allowed words (for example `PathFinding = 0/1/2`, `IdFactory` types, `DropAdena…`): a drop-down with the listed values.
   - **Lists, colours, times and everything else:** text fields. A colour key (hex) also gets a colour preview swatch.
   - **Values that don't fit the control:** a text field with a warning (as G-05 does now).
3. **Kept from G-05:**
   - the help text from the comments;
   - the default value with "reset";
   - the changed marker;
   - masked secrets;
   - saving only the changed keys, in place;
   - "restart needed" per server after saving.
   - **New:** a "Changed settings" list before saving, showing old and new value per key.
4. **Polish:** two columns on wide windows; the topic list and the settings scroll independently; keyboard search (Ctrl+F); dark and light themes as the rest of the GUI.
