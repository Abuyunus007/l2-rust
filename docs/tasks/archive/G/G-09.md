## Goal
1. **Port `DynamicExpRates.xml`.** No Rust loader reads it yet.
   - Port Java `DynamicExpRateData` (the loader, `isEnabled`, `getDynamicExpRate(level)`, `getDynamicSpRate(level)`).
   - Port its use in `Npc.getExpReward` and `Npc.getSpReward`.
   - Port any other caller (search the Java for `DynamicExpRateData`).
   - Wire it in the game server's datapack load.
   - Tests: the file enabled and disabled; one level from the shipped table.
2. **XML entities in the hand-written quick-xml readers.**
   - quick-xml 0.42 reports `&amp;` and other references as `Event::GeneralRef`. Readers that only collect `Event::Text` silently drop them: `crates/game-server/src/client/secondary.rs` (`recoveryLink`), and check `newchar.rs`, `l2-data/src/multisell.rs`, `l2-data/src/stats/node.rs`, `world_data.rs`, `ipconfig.rs` and every other `Event::Text` user (`grep -rn "Event::Text" crates`).
   - Resolve the five predefined entities and numeric character references as Java's parser does. A shared helper in `l2-data` or `l2-config` is fine.
   - Test each reader with a `&amp;` value.
3. **One config view.**
   - Embed the G-08 XML forms into the G-07 topic list as an "XML configs" group, using the `topic_list` and `form_ui` hooks of `XmlConfigView`.
   - Remove the separate "XML configs" nav entry, so all configuration is in one place.
   - Search finds XML topics by file name too.
4. **ClassMaster:** show the `setNoble` and `setHero` switches in the form.
