## Goal
The supervisor makes database backups on a schedule and on request. The GUI shows them.

1. **Rust-only `Backup.ini`** next to `supervisor.ini`, with these keys:
   - `Enabled` (default False);
   - `IntervalHours` (24);
   - `Keep` (7);
   - `Folder` (`backups`);
   - `MysqldumpPath` (empty: look on the PATH, then the usual MariaDB/MySQL install folders on Windows);
   - `DatabaseIni` (default `../login/config/Database.ini`, to read host, port, user, password and database name from there; the password is never logged).
2. **A backup** is `mysqldump --single-transaction --routines --events <db>`, written gzip-compressed to `<Folder>/<db>-YYYYMMDD-HHMMSS.sql.gz`. Pass the password through the `MYSQL_PWD` environment variable or a temp option file deleted afterwards, never on the command line. Keep the newest `Keep` files.
3. **Admin API:** `BackupNow`, `ListBackups` (name, size, time) and `BackupState` (running / last result).
4. **GUI:** a Backups view with "Backup now", the list, the last result and the next run. "Restore" is a dialog that only shows the command to run (no automatic restore).
5. **The switch** (M9-S01) runs a backup first.

## Requirements
- Never connect to a real database in tests. Test with a fake `mysqldump` script (a test helper binary) that writes a known output. Also test the file naming, rotation, and building the command line without the password.
