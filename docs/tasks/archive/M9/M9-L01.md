## Goal
The parts the custom cards left out. Each item is separate. Do them in this order and report every item you could not finish.

1. **Offline play after a restart.** Port `RestoreAutoPlayOffliners`: the `character_offline_play` and `character_offline_play_group` rows (store them, restore at startup, `storeOfflineGroups`).
   - Write and restore only with `OfflineTradeDatabaseWrites` (D-52), so the Java server and the Rust server never restore the same characters.
   - Also port `OfflineDisconnectSameAccount` and `OfflinePlayDisconnectSameAccount`: the hook where the game server builds the character list.
   - Also add the dual-box `OFFLINE_PLAY` count (`AntiFeedManager`, from M9-C06) to the CharacterSelect premium / offline-play branch.
2. **Buff shop offline trade.** A seller of the buff shop (type 9) is saved and restored like the other offline traders, under the same switch (D-52).
3. **Auto play.**
   - Pet skills from `PetSkillData.getKnownSkill/getKnownSkills`.
   - Enchant-option and augmentation skills are left out of the `.playskills` list, as in Java.
   - The captcha kill counter skips a player in auto play, as in Java.
4. **Fake players.**
   - A bot report on a fake player behaves as in Java.
   - The follow intention after clicking a fake player.
   - A herb dropped for a fake player casts its skill.
   - Monsters aggro fake players, as Java's scan does.
   - `//reload fakeplayerchat`.
5. **Multilingual support, part 2.**
   - Localise packets: NPC names, NPC strings, system messages and `sendMessage`, using `data/lang/<lang>/`.
   - Put the language into CharSelectionInfo.
   - Read and write the `characters.language` column.
6. **Codegen list types.** The `()` fields of the generated config structs (lists, maps) become real types with Java's parsing. Remove the hand-read duplicates in `custom_monsters.rs`, `npcs.rs` and `custom_misc_data.rs`, and keep one source.
7. **Tests that were missing.**

   - `_bbspremium` on the board.
   - The Olympiad dual-box wiring with client IPs (add an IP to the Olympiad test scene).
