## Goal
Vectors from the real `Formulas` code for everything skills need, so M5-FORM-02 can be checked
number for number: `calcMagicDam` (sps/bss, m.crit), `calcMCrit`, `calcPhysDam` with a skill,
`calcBlowDamage`, `calcBackstabDamage`, `calcBlowSuccess`, `calcEffectSuccess`, `calcMagicSuccess`,
`calcMagicAffected`, `calcSkillMastery`, `calcEffectAbnormalTime`, `calcAtkSpd` for skills (cast and
reuse times incl. `Creature.getSkillReuseTime`-style parts that are pure numbers), `calcManaDam`,
`calculateSkillResurrectRestorePercent`, `calcGeneralTraitBonus` with traits, `calcAttributeBonus`
with elements, and the heal formula of the `Heal` effect (`Heal.onStart` number part).
