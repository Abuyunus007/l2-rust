## Goal
End-to-end tests in `crates/game-server/tests/e2e_scripts.rs` that drive the real game server over the client protocol with the real script registry (`l2_scripts::register_all` or what game-server installs), like M6..M8's:
1. A new character: the tutorial start, a first village quest (talk, kill, reward), and aborting a quest (CP-Sa).
2. 1st class change at a village master and a subclass add, switch and cancel (skills and hennas follow) (CP-Sb).
3. A Kamaloka or Pailaka enter, a kill inside, leave, and the re-enter time (CP-Sc).
4. A raid boss with its AI starting a fight, and a grand boss whose row says dead staying unspawned on Kain (D-54).
5. Side by side (CP-Sd): a `character_quests` row in progress written by "Sieghardt" (seeded) is continued after login; `global_variables` untouched with `CycleDatabaseWrites` off, written with it on.
DB variants run only under `L2_TEST_DATABASE_URL`; the rest uses the in-memory store as the other e2e files do.
