## Requirements
1. `e2e.rs` covers all milestone-1 behaviours from doc 01 in one suite (gated on the DB): auth success/failure, IP ban, auto-create, account in use + kick, GM-only server, server login, GS auth request, GS disconnect → server shown as down.
2. A capture comparison: replaying a JSONL capture of a Java LS session (recorded with the proxy, stored under `fixtures/captures/`, account data scrubbed) gives the same packet *types and fields* from the Rust LS, ignoring random values (session id, keys).
3. The runbook is written for a beginner: exact commands, expected log lines, what "pass" looks like.
