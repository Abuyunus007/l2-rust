## Requirements
1. Link framing: the same u16-LE framing via `l2-net`, body via `LinkCipher` (default key, then the 40-byte key from BlowFishKey after the RSA-512 decrypt with leading zeros stripped).
2. The registration decision table is ported 1:1 and covered by tests: known id + same hexid; known id + already authed → `REASON_ALREADY_LOGGED8IN`; unknown id + AcceptNewGameServer; wrong hexid + alternate allowed → first free id; no free id → `REASON_NO_FREE_ID`; etc.
3. `hexid` string encoding identical to Java (`BigInteger.toString(16)`, including a leading `-` for negative values), so existing `gameservers` rows from Java keep working (the sample row `-2ad66b3f...` must round-trip). Careful: `stringToHex(hexToString(b))` is **not** always `b` (BigInteger drops redundant leading 0x00/0xFF bytes), and Java compares the DB-decoded bytes with the GS's raw hexid via `Arrays.equals`. Port this exactly, add a test for a hexid starting with 0x00, and mark it `// NOTE(java-quirk)`.
4. On disconnect: mark the server down, remove the link, keep it in the table.
5. Banned-GS IP check: Java has a TODO stub that returns false. Port the stub as is with `// NOTE(java-quirk)`.
