## Requirements
1. The 500 ms character wait is an **async wait with timeout** on a notify/watch (no sleeping loop), returning as soon as the replies from all authed GSes are in.
2. Subnet matching ported exactly from `Subnet.java` (CIDR and mask forms, IPv4).
3. `lastServer` update in the DB only when the server changes (as Java).
4. Purge every 5 min: close sessions that haven't joined a GS within 5 min, plus disconnected ones, with `LoginFail(ACCESS_FAILED)`.
