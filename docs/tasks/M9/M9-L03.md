## Goal
Several generated config fields are typed `()`: the lists, maps and sets, for example `champion_reward_items`, `raidbosses_excluded_*`, `mobs_list_not_random`, the community board lists and the custom misc lists. Each card then read them by hand from the `.ini` file.

1. Teach `codegen` the Java parsing of these kinds: int list, int set, int-to-int map, item holder list, location list, string list. Use the separators and error handling of Java's config loaders.
2. Regenerate the config with `cargo run -p codegen -- config`. Never edit the generated files by hand.
3. Remove the hand-read copies, so there is one source for each key:
   - `game-server/src/{custom_monsters,npcs,custom_misc_data,world_data}.rs`;
   - `l2-config/src/game_manual*.rs` where they duplicate a key.
4. Behaviour stays byte-identical: the same values reach the world.

## Tests
