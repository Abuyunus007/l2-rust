## Goal
`AttackableAI` for monsters: aggro list (hate/damage), aggression (`aggroRange`, `isAggressive`, level/faction rules), attack intention, chase with move-to-pawn, return home / give up (drift range, `MaxDriftRange`), minion/leader following, faction call (`clan`/`clanHelpRange`). Runs in the tick for NPCs in active regions only, at Java's think interval.
