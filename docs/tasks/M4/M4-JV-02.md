## Goal
M4-DROP-01's `calculate_drops` is checked only against self-made tests. JV-01's harness already
replaces `Rnd` with a scripted, recording copy, so the real `NpcTemplate.calculateDrops` (and the
`Attackable.doItemDrop` parts that are pure numbers) can produce vectors: for a set of NPCs (normal
monsters, a raid boss, NPCs with group lists, with level gaps of 0/5/9/10/15 to the killer, with
the shipped `Rates.ini` and with a few custom rate settings) the scripted draws, every recorded
`Rnd` call and the resulting drop list (item id, count).
